 Projeto SQL — Loja de Informática

 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos de SQL e MySQL, criando e manipulando um banco de dados para uma loja de informática.

Durante o desenvolvimento, foram aplicados conceitos de criação de banco de dados, criação e relacionamento de tabelas, inserção de dados e consultas SQL.

Tecnologias utilizadas

- MySQL
- SQL
- GitHub
- MySQL Workbench

 Estrutura do banco de dados

O banco de dados `loja_informatica` possui as seguintes tabelas:

- **categorias** — armazena as categorias dos produtos.
- **produtos** — armazena os produtos, preços e estoque.
- **clientes** — armazena os dados dos clientes.

A tabela `produtos` possui um relacionamento com a tabela `categorias` por meio de uma chave estrangeira.
